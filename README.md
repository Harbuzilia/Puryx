## 💡 Почему Puryx

- **Многоуровневая безопасность удаления.** Белый список glob-паттернов (AI-агенты, сохранения игр, git-репозитории, базы данных), 24-часовой защитный период для пользовательских данных, проверка файловых блокировок.
- **Корзина по умолчанию.** Все удаляемые файлы отправляются в Корзину с мгновенным восстановлением; карантин — изолированное хранилище с безопасным возвратом в исходные каталоги.
- **Подписанный elevated-протокол.** Запрос на повышенную очистку подписывается HMAC-SHA256 на основе одноразового auth-токена, ограничен сроком действия (TTL) и защищён от replay через nonce; принимаются только запросы из временной папки с разрешёнными корнями.
- **16 сканеров в одном приложении** — от системных кэшей и браузеров до node_modules, pip, WSL2, Docker и шейдерных кэшей GPU.
- **19 специализированных разделов и инструментов** — от NTFS Compact и Game Boost до поиска дубликатов, DiskMap и деинсталлятора.
- **Плагины на JSON-манифестах.** Новые правила очистки подключаются файлом `*.plugin.json` без изменения кода — встроенные и пользовательские манифесты.
- **Portable-режим.** Маркер `portable.txt` рядом с исполняемым файлом переносит конфигурацию в портативную сборку — без следов в `%APPDATA%`.
- **Fluent UI с темами.** Windows 11 Fluent Design, переключение тёмной/светлой/системной темы с сохранением предпочтений.
- **349 unit-тестов** (xUnit) покрывают движок очистки, безопасность, плагины, дубликаты и CLI-инспектор.

## 🧰 19 специализированных разделов и инструментов

1. **Дашборд и статистика**:
   - KPI-метрики освобождённого пространства, сессий очистки и удалённых файлов.
   - Исторические диаграммы освобождённого места по неделям.

2. **Очистка диска**:
   - Профили сканирования (*Быстрая*, *Разработка*, *Полное*).
   - Полнотекстовый поиск (`Ctrl+F`), безопасный выбор (`Ctrl+A`), сортировка по размеру, пути и риску.
   - Экспорт результатов в CSV и JSON.

3. **Глубокая очистка системы (System Deep Clean)**:
   - Анализ и сжатие хранилища компонентов WinSxS (`Dism.exe /ResetBase`).
   - Очистка старых версий драйверов устройств (Driver Store).

4. **Сжатие диска (Compact NTFS)**:
   - Прозрачное сжатие системных файлов и приложений алгоритмами Windows CompactOS (XPRESS4K, XPRESS8K, XPRESS16K, LZX) без потери производительности.

5. **Оптимизация RAM (Ram Optimizer & Game Boost)**:
   - Сброс рабочего набора процессов (EmptyWorkingSet), очистка Standby List и Modified Page List.
   - Игровой турбо-режим (Game Boost): принудительная приостановка фоновых ресурсоёмких служб на время игровых сессий.

6. **Оптимизатор сети и DNS**:
   - 1-Click сброс DNS-кэша (`ipconfig /flushdns`), Winsock и сетевого стека TCP/IP.
   - Тестирование задержки (Ping) публичных DNS-серверов (Cloudflare, Google, Quad9) с возможностью быстрого переключения.

7. **Защита приватности (Anti-Spy Telemetry Debloater)**:
   - Отключение телеметрии, диагностических данных DiagTrack, WAP Push, рекламы в Explorer и меню Пуск, WER и геолокации.
   - Резервное копирование параметров реестра перед применением твиков и откат в 1 клик.

8. **Оптимизатор служб Windows**:
   - Готовые пресеты (Игровой / Max FPS, Сбалансированный, Офисный) для безопасного отключения неиспользуемых фоновых служб.
   - Снимок исходного состояния служб и откат по умолчанию.

9. **Поиск дубликатов**:
   - 4 режима: поиск дубликатов (SHA-256 / Turbo-хэш / побайтовое сравнение), поиск по образцу, сравнение двух папок, журнал удалений.
   - Встроенный предпросмотр изображений и текста.

10. **Карта диска (DiskMap)**:
    - Интерактивная визуализация дискового пространства в виде Squarified TreeMap с цветовой дифференциацией по глубине и возможностью зума.

11. **Большие файлы**:
    - Быстрый поиск и сортировка самых тяжелых файлов на диске с фильтрацией по минимальному размеру и количеству.

12. **Автозагрузка**:
    - Анализ элементов автозапуска (Реестр Run/RunOnce, папки автозагрузки, планировщик), включение/выключение и удаление.

13. **Деинсталлятор программ**:
    - Пакетное удаление приложений Win32 и UWP с поиском остаточных файлов в реестре и на диске.

14. **Инспектор CLI**:
    - Инвентаризация и очистка кэшей пакетных менеджеров (npm, pip, cargo, nuget, vcpkg) и консольных утилит.

15. **AI-Ассистент**:
    - Интеллектуальный помощник для анализа дискового пространства и рекомендаций по безопасной очистке.

16. **Карантин**:
    - Изолированное хранилище удалённых файлов с возможностью безопасного восстановления в исходные каталоги.

17. **Планировщик**:
    - Автоматическая очистка по расписанию через Планировщик заданий Windows (ежедневно / еженедельно) в тихом фоновом режиме.

18. **Плагины**:
    - Модульная архитектура с поддержкой внешних сканеров и пользовательских правил очистки.

19. **Обнаружение приложений**:
    - Эвристический поиск неизвестных программ с накопленным кэшем и добавление в базу знаний.

## 🛡️ Безопасность

- **Многоуровневая защита:** белый список glob-паттернов (AI-агенты, сохранения игр, git-репозитории, базы данных), 24-часовой защитный период для пользовательских файлов, проверка файловых блокировок.
- **Удаление в Корзину:** по умолчанию все файлы отправляются в Корзину с возможностью мгновенного восстановления.
- **Карантин:** удалённые объекты изолируются в отдельное хранилище с безопасным восстановлением по исходному пути.
- **Elevated Cleaning:** отдельный процесс с UAC-повышением прав запускается только для системных каталогов — по подписанному запросу с auth-токеном, TTL и защитой от повторного использования.

## 📦 Сборка и запуск

```bash
# Сборка проекта
dotnet build SmartCleaner.sln

# Запуск тестов
dotnet test SmartCleaner.sln

# Интерактивное меню сборки и публикации
build.bat

# Portable-сборка одним файлом (release\portable\SmartCleaner.App.exe)
publish_portable.bat
```

`build.bat` без аргументов открывает меню: Debug/Release-сборка, тесты, portable-публикация, запуск, очистка, restore.

> **SmartScreen.** Приложение не подписано код-подписью: при первом запуске Windows SmartScreen покажет предупреждение — нажмите «Подробнее» → «Выполнить в любом случае». Подпись кода запланирована в v3.0 ([docs/ROADMAP.md](docs/ROADMAP.md)).

## 🧑‍💻 Разработка

### Структура решения

| Проект | Назначение |
|--------|------------|
| `SmartCleaner.App` | WPF-приложение: Views, ViewModels, DI-регистрация в `App.xaml.cs` |
| `SmartCleaner.Core` | Доменная логика: сканеры, очистка, безопасность, плагины, оптимизация |
| `SmartCleaner.Core.Tests` | xUnit-тесты движка очистки, безопасности и плагинов |
| `SmartCleaner.Data` | Встроенные плагины `Plugins/*.plugin.json` (копируются в сборку) |

Решение — `SmartCleaner.sln`, точка входа DI — `SmartCleaner.App/App.xaml.cs`.

### Как добавить сканер

1. Реализуйте `IScannerStrategy` в `SmartCleaner.Core/Scanning/Scanners/` (`CategoryName`, `CategoryIcon`, `DisplayOrder`, `IsEnabledByDefault`, `ScanAsync`).
2. Зарегистрируйте сканер в DI: `services.AddSingleton<IScannerStrategy, MyScanner>();` в `App.xaml.cs`.

### Как добавить правило очистки через плагин

Манифест `*.plugin.json` содержит `Id`, `Name`, `Version`, `Category`, `Rules` (шаблоны путей `PathTemplate`, `Pattern`, `Recursive`, `Excludes`). Копируется в `Plugins/` рядом с приложением или в `%APPDATA%\SmartCleaner\Plugins`. Любой путь от плагина проходит ту же проверку безопасности и удаляется только в Корзину.

### Кодовые имена

Кодовая база исторически называется `SmartCleaner.*`: пространства имён, сборка `SmartCleaner.App.exe`, решение `SmartCleaner.sln` и команды сборки не переименованы. Пользовательское название проекта — **Puryx**.
