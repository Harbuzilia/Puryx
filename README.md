# 🧹 Smart System Cleaner (CHISTilka) — Full Suite v2.7.1

**Комплексная утилита очистки, анализа, защиты приватности и глубокой оптимизации Windows** — WPF-приложение на .NET 8 LTS с интерфейсом Fluent Design, 18+ модулями сканирования, инструментами сжатия NTFS Compact, оптимизацией оперативной памяти, управлением службами и защитой от телеметрии.

---

### 19 специализированных разделов и инструментов

1. **Дашборд и статистика**:
   - KPI-метрики освобождённого пространства, сессий очистки и удалённых файлов.
   - Исторические диаграммы освобождённого места по неделям.

2. **Очистка диска**:
   - Профили сканирования (*Быстрая*, *Разработка*, *Полное*).
   - Полнотекстовый поиск (`Ctrl+F`), безопасный выбор (`Ctrl+A`), сортировка по размеру, пути и риску.
   - Экспорт результатов в CSV и JSON.

3. **Глубокая очистка системы (System Deep Clean)**:
   - Анализ и сжатие хранилища компонентов WinSxS (`Dism.exe /ResetBase`).
   - Очистка старых версий драйверов устройств (Driver Store).
   - Очистка теневых копий VSS и точек восстановления системы.

4. **Сжатие диска (Compact NTFS)**:
   - Прозрачное сжатие системных файлов и приложений алгоритмами Windows CompactOS (XPRESS4K, XPRESS8K, XPRESS16K, LZX) без потери производительности.

5. **Оптимизация RAM (Ram Optimizer & Game Boost)**:
   - Сброс рабочего набора процессов (EmptyWorkingSet), очистка Standby List и Modified Page List.
   - Игровой турбо-режим (Game Boost): принудительная приостановка фоновых ресурсоёмких служб на время игровых сессий.

6. **Оптимизатор сети и DNS**:
   - 1-Click сброс DNS-кэша (`ipconfig /flushdns`), Winsock и сетевого стека TCP/IP.
   - Тестирование задержки (Ping) публичных DNS-серверов (Cloudflare, Google, Quad9) с возможностью быстрого переключения.

7. **Защита приватности (Anti-Spy Telemetry Debloater)**:
   - Отключение телеметрии, диагностических данных DiagTrack, WAP Push, рекламы в Explorer и меню Пуск, WER и геолокации.
   - Резервное копирование параметров реестра перед применением твиков и откат в 1 клик.

8. **Оптимизатор служб Windows**:
   - Готовые пресеты (Игровой / Max FPS, Сбалансированный, Офисный) для безопасного отключения неиспользуемых фоновых служб.
   - Снимок исходного состояния служб и откат по умолчанию.

9. **Поиск дубликатов**:
   - 4 режима: поиск дубликатов (SHA-256 / Turbo-хэш / побайтовое сравнение), поиск по образцу, сравнение двух папок, журнал удалений.
   - Встроенный предпросмотр изображений и текста.

10. **Карта диска (DiskMap)**:
    - Интерактивная визуализация дискового пространства в виде Squarified TreeMap с цветовой дифференциацией по глубине и возможностью зума.

11. **Большие файлы**:
    - Быстрый поиск и сортировка самых тяжелых файлов на диске с фильтрацией по минимальному размеру и количеству.

12. **Автозагрузка**:
    - Анализ элементов автозапуска (Реестр Run/RunOnce, папки автозагрузки, планировщик), включение/выключение и удаление.

13. **Деинсталлятор программ**:
    - Пакетное удаление приложений Win32 и UWP с поиском остаточных файлов в реестре и на диске.

14. **Инспектор CLI**:
    - Инвентаризация и очистка кэшей пакетных менеджеров (npm, pip, cargo, nuget, vcpkg) и консольных утилит.

15. **AI-Ассистент**:
    - Интеллектуальный помощник для анализа дискового пространства и рекомендаций по безопасной очистке.

16. **Карантин**:
    - Изолированное хранилище удалённых файлов с возможностью безопасного восстановления в исходные каталоги.

17. **Планировщик**:
    - Автоматическая очистка по расписанию через Планировщик заданий Windows (ежедневно / еженедельно) в тихом фоновом режиме.

18. **Плагины**:
    - Модульная архитектура с поддержкой внешних сканеров и пользовательских правил очистки.

19. **Обнаружение приложений**:
    - Эвристический поиск неизвестных программ с накопленным кэшем и добавление в базу знаний.

## 🛡️ Безопасность

- **Многоуровневая защита:** Белый список glob-паттернов (AI-агенты, сохранения игр, git-репозитории, базы данных), 24-часовой защитный период для пользовательских файлов, проверка файловых блокировок.
- **Удаление в Корзину:** По умолчанию все файлы отправляются в Корзину с возможностью мгновенного восстановления.
- **Elevated Cleaning:** Запуск отдельного процесса с UAC-повышением прав только для системных каталогов.

## 🎨 Дизайн и интерфейс

- Windows 11 Fluent Design с плавными анимациями, скруглениями и карточным стилем.
- **Динамическое переключение тем:** Тёмная, Светлая или Авто (Системная) с сохранением предпочтений.
- **Горячие клавиши:**
  - `Ctrl + A` — Выбрать все безопасные элементы
  - `Ctrl + F` — Поиск по результатам
  - `Ctrl + S` — Запуск сканирования
  - `Delete` — Запуск очистки выбранного
  - `Escape` — Отмена сканирования
- Интеграция в контекстное меню Проводника Windows («Сканировать в SmartCleaner»).
- Поддержка Drag & Drop папок прямо в главное окно.
